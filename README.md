# 🧠 Core Innovation

## 1️⃣ Behavior-Driven Environmental Modeling

PRAKRITI integrates a deterministic behavioral engine that derives:

-   Risk Tolerance (0--1 normalized)
-   Health Sensitivity
-   Outdoor Affinity
-   Social Energy
-   Structure Preference
-   Analytical Bias
-   Creativity Bias
-   Interest Vector
-   MBTI Classification

All behavior vectors are deterministic, explainable, normalized,
interpretable, disease-aware, and constraint-aware.

# 🧩 Techathon - PRAKRITI Monorepo

## Overview

This repository contains the source code for the Techathon 3.0 -
PRAKRITI project, a comprehensive platform integrating environmental
data, digital twins, and user engagement features.

The project is structured as a monorepo with the following components:

-   **Backend**: A FastAPI-based application handling business logic,
    API endpoints, and AI integration.
-   **Frontend**: A React application built with Vite and styled with
    TailwindCSS for the user interface.

------------------------------------------------------------------------

## Tech Stack

### Backend

-   Framework: FastAPI
-   Package Manager: Poetry
-   Database: Supabase
-   Caching: Redis
-   AI Agent: LangGraph

### Frontend

-   Framework: React (Vite)
-   Styling: TailwindCSS

------------------------------------------------------------------------

# ⚙ Quick Start

## Backend

1.  Navigate to backend:

``` bash
cd backend
```

2.  Install dependencies:

``` bash
poetry install
```

3.  Run application:

``` bash
poetry run python -m src
```

API available at: http://localhost:8000\
Docs: http://localhost:8000/docs

------------------------------------------------------------------------

## Frontend

1.  Navigate to frontend:

``` bash
cd frontend
```

2.  Install dependencies:

``` bash
npm install
```

3.  Start dev server:

``` bash
npm run dev
```

Frontend available at: http://localhost:5173
